**Project Title :** Intelligent NLP Powered Database Analytics System

**Decription :** This project is an Intelligent NLP-Powered Database Analytics System designed to democratize data access. It leverages Large Language Models (LLMs) and Natural Language Processing to translate plain English queries into complex SQL execution plans. By eliminating the need for manual SQL coding, the system enables stakeholders to extract actionable insights, generate visualizations, and perform deep-dive analytics through a simple conversational interface.
